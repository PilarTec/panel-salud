Cambios realizados en el catálogo de hallazgos, triaje y seguridad del proyecto:

<!-- truncate -->

- **Catálogo de Hallazgos - Eliminar clasificaciones:** Ahora se pueden borrar clasificaciones. Al borrarlas, el sistema también elimina en automático los vínculos que tenían asociados para no dejar datos sueltos.
- **Desvincular hallazgos:** Se agregó la opción de desvincular términos si se asignaron a una clasificación por error, regresándolos a la lista de pendientes.
- **Visualización de nuevos hallazgos:** Se rediseñó la vista de hallazgos pendientes para que se vean en tarjetas ordenadas y sea más fácil revisarlos.
- **Filtros en Hallazgos:** Se agregó un buscador y filtros para encontrar diagnósticos rápido sin tener que recorrer toda la lista.
- **Mejora visual para vincular a existente:** Se arregló el menú desplegable al vincular con un hallazgo existente, ya que antes no se podía ver bien el texto.
- **Filtros por nivel de riesgo en el catálogo:** Botones directos para filtrar por nivel de riesgo: Crítico, Alto, Medio, Bajo o ver Todos.
- **Seguridad en GitHub:** Las claves de Firebase se movieron a un archivo `.env` privado y se protegió el `.gitignore` para no subir por error credenciales ni archivos de Excel.
